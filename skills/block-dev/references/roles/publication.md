# Publication Worker Contract

## PR Publisher

**Goal:** Publish one reviewed block branch.

**Inputs:** The passed review reports, block file, branch, parent branch, and [open-github-pull-request.md](../open-github-pull-request.md).

**Write scope:** The scope that `open-github-pull-request.md` permits.

**Actions:**

1. Follow `open-github-pull-request.md` as the publication authority.
2. Return the publication evidence that the authority requires.

**Stop rule:** Do not change implementation files.
